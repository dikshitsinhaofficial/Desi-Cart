# ✨ Overview

DesiCart is a **premium multi-vendor E-Commerce platform** inspired by Amazon and Flipkart.

It is built completely from scratch with a modern UI, secure authentication, powerful backend APIs, seller support, wallet system, Razorpay integration, and an admin dashboard.

Whether you're a customer purchasing products or a seller managing your inventory, DesiCart provides a seamless shopping experience.

# 📦 Installation

Clone Repository

```bash
git clone https://github.com/dikshitsinhaofficial/Desi-Cart.git
```

Move into Project

```bash
cd Desi-Cart
```

Install Dependencies

```bash
npm install

cd frontend
npm install

cd ../backend
npm install
```

---

# 🔑 Environment Variables

Backend

```env
PORT=5000

MONGO_URI=YOUR_MONGODB_URI

RAZORPAY_KEY_ID=YOUR_KEY

RAZORPAY_KEY_SECRET=YOUR_SECRET

FRONTEND_URL=http://localhost:4008
```

Frontend

```env
NEXT_PUBLIC_API_URL=http://localhost:5000

NEXT_PUBLIC_FIREBASE_API_KEY=YOUR_FIREBASE_KEY

NEXT_PUBLIC_FIREBASE_AUTH_DOMAIN=

NEXT_PUBLIC_FIREBASE_PROJECT_ID=

NEXT_PUBLIC_FIREBASE_STORAGE_BUCKET=

NEXT_PUBLIC_FIREBASE_MESSAGING_SENDER_ID=

NEXT_PUBLIC_FIREBASE_APP_ID=
```
