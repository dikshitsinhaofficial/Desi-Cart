# 🛒 Desi-Cart

Desi-Cart is a full-stack eCommerce platform inspired by Amazon and Flipkart, designed to help sellers across India showcase and sell their products online. The platform provides a seamless shopping experience for customers with secure payments, wallet functionality, and multiple payment options.

---

## 🚀 Features

* 🛍️ Modern eCommerce platform
* 👨‍💼 Multi-seller product management
* 🔍 Product browsing and search
* 🛒 Add to Cart & Checkout system
* 💳 Secure Razorpay payment integration
* 💰 Multiple payment methods:

  * Cash on Delivery (COD)
  * Wallet Payment
  * UPI / Debit Card / Credit Card / Net Banking
* 📦 Order management system
* 👤 User authentication & authorization
* 📱 Responsive UI for all devices

---

## ⚙️ Installation & Setup

### Clone the repository

```bash
git clone https://github.com/dikshitsinhaofficial/Desi-Cart.git
cd Desi-Cart
```

### Install dependencies

#### Frontend

```bash
cd frontend
npm install
```

#### Backend

```bash
cd backend
npm install
```

---

## ▶️ Run the Project

### Start Frontend

```bash
npm run dev
```

### Start Backend

```bash
npm start
```
